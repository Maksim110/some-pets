# Классификация изображений с использованием ResNet18

писание проекта

В данном проекте реализована модель для задачи классификации изображений с использованием методов глубокого обучения. Основной акцент сделан не только на архитектуре модели, но и на корректной организации пайплайна обработки данных.

---

 Модель

Используется предобученная архитектура
ResNet18

Сеть применяется в режиме transfer learning: сверточная часть используется как экстрактор признаков, а последний слой переобучается под конкретную задачу.

---

 Работа с данными

1. Структура данных

Данные организованы в виде датасета изображений, где каждому изображению соответствует метка класса.
Метки кодируются в виде целых чисел

Создаётся отображение:

* `class_to_idx` - соответствие между именами классов и их числовыми индексами

---

 2. Предобработка изображений

Перед подачей в модель изображения проходят последовательность преобразований:

* приведение к фиксированному размеру (resize)
* преобразование в тензор (`ToTensor`)
* нормализация

Нормализация выполняется по статистикам ImageNet

Это необходимо для корректной работы предобученной модели.

---

3. Разделение выборки

Данные разбиваются на:

* обучающую выборку (`train_loader`)
* валидационную выборку (`val_loader`)
* тестовую выборку (`test_loader`)

Такое разделение позволяет:

* обучать модель на одной части данных
* оценивать качество на независимой выборке

---

 4. Использование DataLoader

Для эффективной работы с данными используются объекты `DataLoader`, которые обеспечивают:

* пакетную загрузку данных (batch processing)
* перемешивание обучающей выборки (`shuffle=True`)
* параллельную загрузку (при необходимости)

Формат батча:

```id="bt9x1q"
images: Tensor [B, C, H, W]
labels: Tensor [B]
```

где:

* (B) - размер батча
* (C) - число каналов (3 для RGB)

---
 5. Передача данных в модель

На каждом шаге обучения:

* данные переносятся на устройство (`CPU` или `GPU`)
* метки приводятся к типу `long`, необходимому для функции потерь

```python id="xkq3mv"
inputs = inputs.to(device)
labels = labels.to(device).long()
```

---

 6. Особенности пайплайна

* модель ожидает вход формата **RGB (3 канала)**
* метки должны быть **целочисленными и начинаться с 0**
* порядок классов фиксируется через `class_to_idx`



---

 Обучение модели

Используются:

* функция потерь: CrossEntropyLoss
* оптимизатор: Adam
* scheduler для изменения learning rate
* early stopping для предотвращения переобучения

---

 Результаты

В процессе обучения отслеживаются:

* loss (train / validation)
* accuracy (train / validation)

Определяется лучшая эпоха по валидационной точности, после чего веса модели восстанавливаются.

 Визуализация

Строятся графики:

* функции потерь
* точности

Они используются для анализа:

* сходимости
* переобучения
